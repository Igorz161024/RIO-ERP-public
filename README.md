# RIO-ERP
RIO-ERP — це нова ERP-система з бекендом на FastAPI та фронтендом на RIO.  
Проєкт створений для дипломної роботи та подальшого розвитку у продакшн-середовищі.

## Структура
- **backend/** — бекенд на FastAPI + SQLAlchemy
- **frontend_rio/** — новий фронтенд на RIO
- **docker-compose.yml** — конфігурація контейнерів (Postgres, бекенд, nginx, backup)

## Запуск
```bash
docker compose up -d
